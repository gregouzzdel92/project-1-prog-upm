# 1) Respect de l’énoncé du projet

## ✔ Points conformes

* **Programme en C++** → conforme à l’exigence ANSI C/C++ 
* **Structure multi-fichiers** (`.cpp` + `.h`) → conforme
* **Organisation logique** :

  * `main.cpp` = orchestration
  * modules séparés : `algorithm`, `display`, `experimentation`, `table_generation`
* **Pipeline expérimental présent** :

  1. Paramètres utilisateur
  2. Génération des données
  3. Exécution de l’expérimentation
  4. Affichage des résultats

➡️ Cela correspond bien aux phases demandées (analyse + expérimentation) 

## ⚠️ Points à vérifier / améliorer

* **Mesures expérimentales** :

  * L’énoncé exige explicitement :
    *comparaisons, mouvements, temps* 
    → Vérifier que ces métriques sont bien mesurées dans `algorithm.cpp` ou `experimentation.cpp`
* **Cas expérimentaux** :

  * pire cas / meilleur cas / cas moyen
    → pas visible ici → à confirmer
* **Fiabilité expérimentale** :

  * répétitions / moyenne / variance non visibles
    → souvent attendu pour une note maximale
